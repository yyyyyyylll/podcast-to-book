# 对谈类播客 · 板块框架

## 类型特征
- 两位或多位嘉宾地位对等
- 双方都在表达观点，有交锋和碰撞
- 话题随讨论自然流转

## 板块框架

### 1. 导读（introduction）
- **作用**：介绍对话背景、双方身份、为什么这个话题重要
- **内容来源**：AI 基于全文总结生成
- **篇幅**：500-800字
- **标题示例**："当一个乐观主义者遇上一个悲观主义者"、"两个产品人的深夜对话"

### 2. 共识地带（consensus）
- **作用**：呈现双方都认同的观点，建立讨论基础
- **内容来源**：提取双方认同的论述
- **要求**：说明为什么这些共识有价值
- **篇幅**：1000-2000字
- **标题示例**："我们都同意的三件事"、"讨论的起点：这些不需要争"

### 3. 观点碰撞（viewpoint_clash）
- **作用**：呈现双方最精彩的分歧，保留争论张力
- **内容来源**：提取碰撞最激烈的讨论段落，保留双方原话
- **要求**：公平呈现双方，不偏不倚；保留语气和力度
- **篇幅**：2000-4000字
- **标题示例**："AI产品该不该有灵魂"、"效率和体验，你选哪个"

### 4. 各自的方法论（methodologies）
- **作用**：双方各自分享的实操经验和思维框架
- **内容来源**：提取各自的方法论和经验
- **要求**：标注是谁的方法论，对比呈现
- **篇幅**：1500-2500字
- **标题示例**："两套完全不同的产品决策框架"、"同一个问题，两种解法"

### 5. 案例交锋（case_exchange）
- **作用**：双方用各自的案例支撑观点
- **内容来源**：提取双方分享的案例和故事
- **要求**：案例和观点对应，让读者自行判断
- **篇幅**：1500-2500字
- **标题示例**："两个数据说了相反的话"、"他的成功案例恰恰是对方的反面教材"

### 6. 延伸思考（extended_thinking）
- **作用**：从碰撞中提炼更深层的洞察
- **内容来源**：AI 延伸生成
- **篇幅**：800-1500字
- **标题示例**："答案也许在碰撞之外"、"值得继续想的三个问题"

## 可选板块
- **背景补充**（context）：如果讨论的话题需要背景知识
- **读者立场选择**（reader_choice）：整理关键分歧点让读者自行站队
