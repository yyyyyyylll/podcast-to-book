# 圆桌类播客 · 板块框架

## 类型特征
- 三人或以上参与讨论
- 多视角、多立场
- 可能有主持人协调

## 板块框架

### 1. 导读（introduction）
- **作用**：话题背景、参与者介绍、为什么讨论这个
- **内容来源**：AI 总结生成
- **篇幅**：600-1000字
- **标题示例**："三个不同立场的人坐在一起聊 XX"

### 2. 议题全景（topic_landscape）
- **作用**：呈现讨论的核心议题和各方基本立场
- **内容来源**：提取各方对核心问题的基本态度
- **要求**：公平呈现每个人的立场，让读者看到全貌
- **篇幅**：1500-2500字
- **标题示例**："关于 XX，三个人给出了三个答案"、"同一个问题的三种打开方式"

### 3. 深度交锋（deep_debate）
- **作用**：最精彩的讨论碰撞，保留多方交锋的张力
- **内容来源**：提取讨论最激烈、最有深度的段落
- **要求**：保留对话的来回感和张力
- **篇幅**：2000-4000字
- **标题示例**："当乐观主义者遇上现实主义者"、"这个问题让三个人吵了半小时"

### 4. 各方锦囊（individual_insights）
- **作用**：每位嘉宾各自最精华的经验分享
- **内容来源**：提取每人的独特贡献（方法论、经验、案例）
- **要求**：标注来源（"XX认为..."），展现个人特色
- **篇幅**：2000-3000字
- **标题示例**："每个人都交了一份不同的作业"

### 5. 案例交汇（cases_convergence）
- **作用**：各方分享的案例汇集，用事实说话
- **内容来源**：提取各方的案例和故事
- **要求**：案例与论点对应，展现多元视角
- **篇幅**：1500-2500字
- **标题示例**："三个截然不同的现场故事"、"谁的数据更有说服力"

### 6. 延伸思考（extended_thinking）
- **作用**：从多元碰撞中提炼洞察，留给读者判断
- **内容来源**：AI 延伸生成
- **篇幅**：800-1500字
- **标题示例**："没有标准答案，但有更好的问题"、"讨论之后，真正重要的是什么"

## 可选板块
- **立场光谱**（stance_spectrum）：可视化呈现各方在关键议题上的位置
- **未完成的辩论**（unfinished_debate）：讨论中未达成共识的问题
