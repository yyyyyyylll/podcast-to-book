# 访谈类播客 · 板块框架

## 类型特征
- 有明确的主持人和嘉宾角色
- 主持人提问引导，嘉宾回答展开
- 嘉宾通常有特定领域的专业知识或经历

## 板块框架

### 1. 导读（introduction）
- **作用**：让读者快速了解"这期聊了什么，为什么值得读"
- **内容来源**：AI 基于全文总结生成
- **要求**：提出本期核心问题，勾起阅读兴趣
- **篇幅**：500-800字
- **标题示例**："为什么每个创业者都该听这一期"、"一个关于增长的反直觉故事"

### 2. 核心观点（core_viewpoints）
- **作用**：提炼嘉宾最重要的 3-5 个观点
- **内容来源**：从原文中提取核心论述，AI 组织表达
- **要求**：每个观点有明确的论述，不是简单罗列；保留嘉宾的原话精华
- **篇幅**：1500-3000字
- **标题示例**："三个反直觉的创业认知"、"关于增长，他说了五句大实话"

### 3. 决策与逻辑展开（decision_logic）
- **作用**：展开嘉宾做重要决策时的思考过程和逻辑链
- **内容来源**：从原文中提取决策相关讨论，AI 梳理逻辑链条
- **要求**：呈现"面临什么问题 → 考虑了什么 → 为什么这么选"的完整链条
- **篇幅**：1500-3000字
- **标题示例**："放弃百万年薪背后的三层思考"、"从 to B 转 to C 的决策复盘"

### 4. 执行路径（execution_path）
- **作用**：具体的操作方法、步骤、可复用的实践经验
- **内容来源**：从原文中提取实操经验，AI 整理为可执行的路径
- **要求**：具体、可操作，读者看完能落地
- **篇幅**：1000-2000字
- **标题示例**："从 0 到 1000 个用户的三步法"、"他的日常管理清单"

### 5. 案例与故事（cases_stories）
- **作用**：用真实故事支撑观点，增强说服力和可读性
- **内容来源**：从原文中提取嘉宾讲述的案例和故事，保留原文叙事
- **要求**：保留故事的细节和情感，不要过度压缩；标注是谁的经历
- **篇幅**：1000-2500字
- **标题示例**："一封拒信改变了产品方向"、"第一个付费用户的故事"

### 6. 延伸思考（extended_thinking）
- **作用**：从具体讨论延伸到更深层的思考，留给读者回味
- **内容来源**：AI 基于全文内容延伸生成，可补充行业背景
- **要求**：有深度，不是简单重复核心观点；可以提出开放性问题
- **篇幅**：800-1500字
- **标题示例**："当 AI 时代遇上创业精神"、"留给每个创业者的三个问题"

## 可选板块（Agent 根据内容判断是否需要）
- **方法论提炼**（methodology）：如果嘉宾分享了可复用的框架/模型
- **争议与碰撞**（debate）：如果主持人和嘉宾有明显分歧
