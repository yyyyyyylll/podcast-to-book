# 独白类播客 · 板块框架

## 类型特征
- 单人长篇输出，有明确的叙事线或论述线
- 说话人通常有深入的思考和准备
- 可能是个人经历分享、观点输出、知识讲解

## 板块框架

### 1. 导读（introduction）
- **作用**：交代背景，说明为什么分享这个话题
- **内容来源**：AI 基于全文总结
- **篇幅**：500-800字
- **标题示例**："一封写了三年的复盘"、"关于 XX 我想说几句真话"

### 2. 核心主张（core_thesis）
- **作用**：说话人最核心的观点或立场
- **内容来源**：从原文中提取核心论述
- **要求**：保留说话人的原话和语气，不要过度改写
- **篇幅**：1500-2500字
- **标题示例**："我为什么不再相信增长黑客"、"三个我花了很多学费才学会的事"

### 3. 心路历程（inner_journey）
- **作用**：展现说话人思考变化的过程
- **内容来源**：提取"过去怎么想→现在怎么想→为什么变了"的内容
- **要求**：保留个人化表达和情感变化
- **篇幅**：1500-3000字
- **标题示例**："从信徒到怀疑者的三百天"、"那个改变一切的下午"

### 4. 方法与实践（methods_practice）
- **作用**：具体的方法论、习惯、操作经验
- **内容来源**：提取实操内容，AI 整理为可执行的形式
- **篇幅**：1000-2000字
- **标题示例**："我的每日思考清单"、"一个反共识的工作方法"

### 5. 故事与细节（stories_details）
- **作用**：用亲身经历的故事支撑观点
- **内容来源**：保留原文中的故事和细节描写
- **要求**：故事是独白类的灵魂，要完整保留
- **篇幅**：1500-3000字
- **标题示例**："凌晨三点的那通电话"、"我和第一个客户的故事"

### 6. 延伸思考（extended_thinking）
- **作用**：从个人经历延伸到更普遍的意义
- **内容来源**：AI 延伸生成
- **篇幅**：800-1500字
- **标题示例**："每个人都在经历自己的至暗时刻"、"答案在路上，不在终点"

## 可选板块
- **时间线**（timeline）：如果内容有强时间线（年终复盘、创业历程等）
- **给读者的话**（letter_to_reader）：如果说话人有直接对听众说的建议
