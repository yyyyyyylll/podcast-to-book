# PodBook 产品需求文档（PRD）

> 版本：v1.0 (MVP)  
> 更新日期：2026-02-25

---

## 1. 产品概述

### 1.1 产品定位
PodBook 是一款面向播客主和内容创作者的工具型产品，通过 AI 技术将播客音频内容转化为可印刷的实体书籍文稿。

### 1.2 目标用户
- **小B端用户**：播客主、自媒体创作者、知识付费讲师
- **核心需求**：将优质播客内容沉淀为实体书籍，拓展内容变现渠道

### 1.3 MVP 范围
本阶段聚焦于**纯音频播客转书籍文稿**，产出为排版后的 PDF 文件。

**包含功能：**
- 音频上传与转写
- AI 文稿处理（6大板块工作流）
- 模板化排版输出 PDF

**不包含功能：**
- 视频内容处理
- 用户登录/账户系统
- 文稿手动编辑
- Canvas 排版编辑器
- POD 按需印刷对接
- 播客链接自动解析

## 3. 功能需求详述

### 3.1 音频上传模块

| 需求项 | 说明 |
|--------|------|
| 支持格式 | MP3、M4A、WAV |
| 文件大小 | MVP 不设上限（建议前端提示超过500MB可能处理较慢） |
| 时长限制 | 不限制 |
| 上传方式 | 本地文件选择上传 |
| 基础信息 | 书名（必填）、作者名（必填）、简介（选填） |
| 模板选择 | 提供 3-5 套预设排版模板 |

### 3.2 AI 文稿处理工作流（6大板块）

#### 板块一：内容解析
| 项目 | 说明 |
|------|------|
| 功能 | 音频ASR转写、声纹识别区分发言人、剔除口语表达、标记时间戳 |
| 输入 | 原始音频文件 |
| 输出 | 按发言人分段的干净转录文稿（JSON结构化） |
| 用户可见 | 是，可预览原始转写结果 |

#### 板块二：内容重组
| 项目 | 说明 |
|------|------|
| 功能 | 判断内容类型、确认核心主题、重组章节结构、生成小标题 |
| 输入 | 板块一输出的结构化文稿 |
| 输出 | 带章节层级的初步书稿 |
| 用户可见 | 是，可预览章节大纲 |

#### 板块三：精华提炼
| 项目 | 说明 |
|------|------|
| 功能 | 抽象方法论、提炼金句、生成章节导语、总结knowhow |
| 输入 | 板块二输出的初步书稿 |
| 输出 | 金句列表、方法论总结、章节思维导图数据 |
| 用户可见 | 是，可预览金句和方法论卡片 |

#### 板块四：文本润色
| 项目 | 说明 |
|------|------|
| 功能 | 统一语气、优化叙事连贯性、调整阅读节奏、增加导语和解释语、补充行业知识 |
| 输入 | 板块二的初步书稿 + 板块三的精华内容 |
| 输出 | 润色后的完整文稿 |
| 用户可见 | 是，可预览润色后文稿 |

#### 板块五：内容注释
| 项目 | 说明 |
|------|------|
| 功能 | 识别专有名词、生成注释（LLM直接解释或联网搜索）、补充背景知识 |
| 输入 | 板块四的润色文稿 |
| 输出 | 注释列表（原文定位 + 注释文本） |
| 用户可见 | 是，可预览注释内容 |

#### 板块六：模拟读者反馈 & 文本修改
| 项目 | 说明 |
|------|------|
| 功能 | AI模拟读者视角提出问题、标记晦涩段落、自动修复问题 |
| 输入 | 板块四、五的文稿和注释 |
| 输出 | 问题列表 + 修复后的终稿 |
| 用户可见 | 是，可查看AI发现的问题及修改对比 |

### 3.3 排版输出模块

| 需求项 | 说明 |
|--------|------|
| 模板选择 | 用户在上传时选择，提供预设模板（商业画册风、典雅艺术风、简约现代风等） |
| 排版引擎 | AI 自动将结构化文稿套用模板生成排版 |
| 输出格式 | PDF（符合印刷标准，300dpi） |
| 封面生成 | 基于书名、作者、全书摘要自动生成封面（通义万相） |
| 插图生成 | 提取关键词进行 AI 图片生成，插入对应章节 |

### 3.4 结果预览与下载

| 需求项 | 说明 |
|--------|------|
| 预览页面 | 展示各板块处理结果（转写、章节、金句、注释等） |
| 进度展示 | 显示当前处理到哪个板块，预估剩余时间 |
| PDF预览 | 在线预览最终排版效果 |
| 下载功能 | 下载完整 PDF 文件 |

## 5. 非功能性需求

### 5.1 性能要求
| 指标 | 目标值 |
|------|--------|
| 音频转写速度 | 1小时音频 < 10分钟处理 |
| 页面加载时间 | < 2秒 |
| 并发处理能力 | MVP阶段支持 5 个任务同时处理 |

### 5.2 兼容性
- 浏览器：Chrome、Safari、Edge 最新两个版本
- 设备：桌面端优先，移动端适配可后续迭代

### 5.3 安全性
- MVP阶段音频文件存储于本地文件系统，后续可切换到阿里云 OSS
- 处理完成后可设置自动清理策略（如7天后删除）

## 6. 数据模型（简化版）

### 6.1 核心实体

```
Task（任务）
├── id: UUID
├── title: 书名
├── author: 作者名
├── description: 简介
├── template_id: 模板ID
├── audio_path: 音频文件路径
├── status: 状态（pending/processing/completed/failed）
├── current_stage: 当前处理板块
├── created_at: 创建时间
└── results: 各板块处理结果（JSONB）
    ├── transcription: 转写结果
    ├── chapters: 章节结构
    ├── highlights: 金句/方法论
    ├── polished_content: 润色文稿
    ├── annotations: 注释
    ├── feedback: 读者反馈问题
    ├── final_content: 终稿
    └── pdf_url: PDF文件地址

Template（模板）
├── id: UUID
├── name: 模板名称
├── preview_image: 预览图
├── config: 排版配置（JSONB）
└── is_active: 是否启用
```

## 7. MVP 里程碑

| 阶段 | 内容 | 交付物 |
|------|------|--------|
| M1 | 基础框架搭建 | 前后端项目初始化、数据库设计、本地存储服务 |
| M2 | 音频转写流程 | 上传 → ASR转写 → 结果存储展示 |
| M3 | AI工作流（板块1-4） | 内容解析、重组、提炼、润色 |
| M4 | AI工作流（板块5-6） | 注释、模拟反馈、修改 |
| M5 | 排版输出 | 模板系统、PDF生成、封面/插图 |
| M6 | 整合测试 | 全流程联调、性能优化 |

## 8. 后续迭代方向（非MVP）

1. **用户系统**：登录注册、历史记录管理
2. **文稿编辑器**：支持用户手动修改AI生成内容
3. **视频内容支持**：画面OCR、截图插入
4. **POD对接**：一键印刷下单
5. **播客链接解析**：支持小宇宙、Apple Podcast等平台链接
6. **协作功能**：多人协作编辑、审批流程
